# ميزان الزكاة | Mizan Zakat ⚖️

حاسبة زكاة احترافية، شاملة، ومستقلة تدعم أكثر من 11 عملة عربية مع أسعار ذهب لحظية.

[English Description Below]

## 🌟 عن المشروع
ميزان الزكاة هو مشروع مفتوح المصدر يهدف لتسهيل حساب الزكاة الشرعية بدقة وثقة. تم بناء المشروع باستخدام أحدث تقنيات الويب لضمان السرعة، الأمان، وسهولة الاستخدام.

### ✨ المميزات
- **حساب شامل:** زكاة الذهب والفضة، النقد، الأسهم، والرواتب.
- **أسعار لحظية:** جلب تلقائي لأسعار الذهب والعملات.
- **دعم العملات:** يدعم أكثر من 11 عملة عربية.
- **خصوصية تامة:** جميع الحسابات تتم في متصفح المستخدم ولا يتم تخزين أي بيانات مالية.
- **جاهز للنشر:** متوافق تماماً مع Cloudflare Pages, Vercel, و Netlify.

## 🚀 التقنيات المستخدمة
- **React 18** & **Vite**
- **TypeScript** (لضمان دقة الكود)
- **Tailwind CSS** (للتصميم العصري)
- **Shadcn UI** (مكونات واجهة مستخدم احترافية)
- **Wouter** (نظام توجيه خفيف وسريع)

## 🛠️ التشغيل المحلي
للمطورين الراغبين في التعديل على المشروع:

```bash
# تثبيت الاعتمادات
npm install

# تشغيل المشروع في وضع التطوير
npm run dev

# بناء النسخة النهائية للنشر
npm run build
```

## 🌟 About the Project
Mizan Zakat is a professional, comprehensive, and independent Zakat calculator supporting over 11 Arabic currencies with real-time gold prices.

### ✨ Features
- **Comprehensive Calculation:** Zakat for Gold, Silver, Cash, Stocks, and Salary.
- **Real-time Data:** Automatic fetching of gold and currency exchange rates.
- **Multi-currency Support:** Supports 11+ Arabic currencies.
- **Full Privacy:** All calculations happen locally in the browser; no financial data is stored.
- **Production Ready:** Fully compatible with Cloudflare Pages, Vercel, and Netlify.

## 🚀 Tech Stack
- **React 18** & **Vite**
